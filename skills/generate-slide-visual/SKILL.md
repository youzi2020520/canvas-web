# Generate Slide Visual

## Workflow

1. State the communication purpose, subject, composition, crop, negative-space requirement, and deck-wide art direction.
2. Reuse the deck consistency key for character, lighting, lens, materials, and palette.
3. Use references as binding image-to-image direction when supplied, without copying text, logos, or identity.
4. Generate one standalone bitmap asset, not a screenshot of a completed slide.
5. Place it as an independently movable image layer with intentional crop, mask, and subject position.

Read [visual-contract.md](references/visual-contract.md) for prompt and placement requirements.

## Preservation Rules

- Do not render visible words, labels, logos, watermarks, or interface chrome into the bitmap.
- Do not flatten editable slide text or vector diagrams into the image.
- Preserve the intended subject when cropping.
