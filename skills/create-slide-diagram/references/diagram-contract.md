# Diagram Contract

Use a stable diagram group with a background-free SVG geometry layer and separate text labels. Each node needs a stable id. Relationships need explicit source and target ids. Keep connectors behind nodes and use a consistent 1.5-2.5px stroke system.

Prefer left-to-right flow for sequences, concentric or hub-and-spoke form for one center with a few peers, swimlanes for ownership, timelines for ordered dates, and matrices for two-dimensional classification. Avoid using a radial layout simply as decoration.

Provide a short accessibility summary that names the starting point, direction, and conclusion.
